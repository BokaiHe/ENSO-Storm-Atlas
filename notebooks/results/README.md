# Computed results

Generated by the research notebook. Inputs are versioned in `../data/manifest.json`; installed versions are recorded in `environment.json`.

| File | Definition |
|---|---|
| `cohorts.csv` | Seasons, storms and finite nine-moment samples by window and phase |
| `seasonal_contrasts.csv` | Three activity contrasts, intervals, raw and Holm p |
| `type_rates.csv` | Four annual type-rate contrasts, intervals, raw and Holm p |
| `type_shares.csv` | Descriptive pooled storm counts and shares by phase and type |
| `cluster_selection.csv` | Silhouette scores for geodesic K=3–7 refits |
| `cluster_assignments.csv` | Refit labels for each storm ID; label integers have no geographic ordering |
| `centroid_decomposition.csv` | Primary total, mix and within-type contrasts; marginal intervals and p values |
| `decomposition_robustness.csv` | Fixed atlas, geodesic K=3–7 and detrended decompositions; conditional 95% intervals; within-model six-component Holm p |
| `period_intensity_sensitivity.csv` | Count contrasts by window and intensity; seasonal sample sizes |
| `leave_one_season_out.csv` | Total centroid point estimates after each season omission |
| `temporal_sensitivity.csv` | All 60 circular phase alignments; raw reference proportions and family-wise Holm adjustments |
| `circular_shift_nulls.csv` | Statistics for every cyclic alignment; shift 0 is observed |
| `moment_contrasts.csv` | Nine storm-weighted mean contrasts and BH q |
| `classification.csv` | Six feature-set AUCs, fold-seed ranges, null ranges, p and BH q |
| `auc_permutation_nulls.csv` | 199 full-pipeline year-label permutation AUCs per feature set |
| `auc_gain_bootstrap.csv` | 1,000 paired season-bootstrap low-order and all-nine AUCs and differences |
| `classification_config.json` | Configuration, sample sizes, paired increment interval and all-nine AUC interval |
| `claim_evidence.csv` | English conclusion-to-evidence map from the executed results |

Activity and type-rate contrasts use **La Niña minus El Niño**. Centroid and moment contrasts use **El Niño minus La Niña**. Coordinate shifts are degrees, not fixed kilometre distances.

Decomposition label permutations test a global no-phase-association null, not separate conditional zero-component nulls. Bootstrap intervals condition on fitted types. Circular shifts preserve cyclic phase order but rely on stationary relative alignment. Null ranges are not confidence intervals. See the notebook for the complete estimands and assumptions.
